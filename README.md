# TORII — каталог фильмов, сериалов, аниме и мультфильмов

Next.js 14 (App Router) + Prisma + PostgreSQL. Проект рассчитан на GitHub + Vercel и базу Neon.

## Что есть

- отдельные разделы **Фильмы / Сериалы / Аниме / Мультфильмы**;
- новый кинематографичный адаптивный интерфейс без боковой панели;
- hero-карусель и кнопка «Удиви меня»;
- поиск и жанры;
- избранное;
- пользовательский прогресс просмотра;
- продолжение с последней серии;
- отметка просмотренных серий;
- админка с настройками оформления и ручной синхронизацией;
- Kodik как текущий источник аниме-каталога и плеера.

## Локальный запуск

Если PowerShell блокирует `npm.ps1`/`npx.ps1`, используй `.cmd`: 

```powershell
npm.cmd install
npx.cmd prisma generate
npx.cmd prisma migrate deploy
npm.cmd run dev
```

Переменные окружения: 

```env
DATABASE_URL="postgresql://..."
DIRECT_URL="postgresql://..."
ADMIN_USER="admin"
ADMIN_PASSWORD="..."
ADMIN_SECRET="..."
KODIK_API_TOKEN="..."
KODIK_API_BASE="https://kodik-api.com"
KODIK_AUTO_TOKEN="true"
KODIK_ANIME_MAX_PAGES="50"
CRON_SECRET="..."
```

Реальные секреты не должны попадать в GitHub.

## Синхронизация Kodik

Torii сохраняет данные Kodik в собственной PostgreSQL-базе: названия, постеры, описания, жанры, источники озвучки, ссылки плеера, сезоны и серии, когда API их возвращает. Для аниме включён постраничный проход `/list`; количество страниц задаётся `KODIK_ANIME_MAX_PAGES`.

Для существующих тайтлов синхронизация дополнительно пытается сопоставлять `kinopoisk_id`, `imdb_id`, `shikimori_id`, а затем название и год.

## AnimeParsers / anime-parsers-ru

Проект `AnimeParsers` (`anime-parsers-ru`) — отдельная Python-библиотека с парсерами AnimeGo, Aniboom, CVH, Kodik и других источников. Текущая документация указывает, что библиотека умеет получать постер/метаданные AnimeGo, список озвучек и данные CVH/Aniboom; она требует Python 3.10+ и не является Node/npm-пакетом.

Поэтому мы пока не встраиваем её прямо в Next.js: для production это лучше делать отдельным Python API/worker. Это позволит протестировать дополнительные источники, не ломая основной каталог.

## Важное

Публичные/сторонние описания API и парсеров не заменяют официальные условия соответствующего сервиса. Используй только те источники и потоки, на которые у тебя есть право размещения/встраивания.
