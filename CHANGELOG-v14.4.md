# TORII v14.4

Что изменено:

- Сохранён новый тёмный дизайн v14.1–v14.3: верхняя навигация без боковой панели, логотип TORII, Hero-карусель, анимации и «Удиви меня».
- Сохранён отдельный раздел «Мультфильмы» и исправлена классификация Kodik: `foreign-cartoon`, `russian-cartoon`, `soviet-cartoon` теперь идут в `cartoon`, а `cartoon-serial` — в `cartoon` + сериал.
- Для аниме Kodik теперь умеет читать несколько страниц `/list`, чтобы старые тайтлы не зависели только от свежего `updated_at`. Число страниц настраивается через `KODIK_ANIME_MAX_PAGES`, по умолчанию 50.
- Добавлено хранение прогресса просмотра в PostgreSQL/Neon через модель `WatchProgress`.
- Для прямого HTML5-видео прогресс сохраняется примерно каждые 10 секунд и автоматически отмечается просмотренным после `ended`.
- Для Kodik при открытии эпизода сохраняется текущая серия; просмотренные серии можно отметить кнопкой `✓`.
- На главной появилась секция «Продолжить просмотр» с переходом на последнюю незавершённую серию и полосой прогресса там, где известна длительность.
- При открытии страницы тайтла пользователь автоматически возвращается к последней незавершённой серии.
- Админка сохранена. Добавлена поддержка категории «Мультфильмы» в валидации создания/редактирования.

## Миграция базы

После распаковки проекта выполните в PowerShell:

```powershell
npm install
npx prisma migrate deploy
npx prisma generate
npm run dev
```

На существующей Neon-базе новая таблица `WatchProgress` будет создана миграцией `202609240001_watch_progress`.

## Важно про Kodik

Автоматическое определение токена остаётся как было. Для глубокой загрузки старого аниме используется параметр `KODIK_ANIME_MAX_PAGES`.

Значение `50` означает до 50 страниц по 100 результатов для аниме; при необходимости его можно изменить в Vercel Environment Variables.

CDNvideoHub в этой версии пока не подключается — это следующий этап после подтверждения рабочего API-доступа партнёра.
